# Repository rules

## No private information

This repository is public. It must not contain anything that is the intellectual property of other repositories or organizations and is not cleared for disclosure: client or company names, private repository names, their file paths, code, schemas, hostnames, URLs, people, metrics, incidents, or any other detail that identifies or reveals them. This applies to skills, examples, evals, fixtures, notes, commit messages, and PR text. Use generic placeholders instead (`example-service`, `orders` table, `acme`).

Two exceptions:
- `ORIGINS.md` may name the internal repositories a skill came from; every other detail there stays anonymized.
- A small script may serve as an eval input or example once scrubbed of identifying names, paths and internal structure.
